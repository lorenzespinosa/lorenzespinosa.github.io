Jelly Workspace

A private connection between Lorenz Espinosa’s personal assistant and Google Drive, designed for owner-approved backup storage and file operations.

What it does

Jelly Workspace is used by the account owner to authorize selected Google Drive operations: creating a backup folder, uploading chosen backup files, reading file metadata to check transfers, and managing those app-associated files when the owner requests it. It is not a public backup service or a file-sharing portal.

This website explains the integration. It does not sign you in to Google, receive authorization codes, or expose backup contents.

Google permissions

  • Google identity: verify the account’s email address and account identifier.
  • Per-file Drive access: see, create, edit, and delete only Drive files created by or explicitly used with this app, through the drive.file permission.

The current connection does not request Gmail, Calendar, Contacts, or unrestricted access to all Drive files. A Google permission is a capability; it does not by itself authorize the assistant to delete, publish, or share a file.

The owner stays in control

Google consent takes place on Google’s own authorization screen. The owner can review or remove the connection through Google Account connections. Removing access does not automatically delete existing files from Drive.

Read the Jelly Workspace privacy policy for how Google data is accessed, used, stored, and shared.

Terms of use

Jelly Workspace is a personal integration operated by Lorenz Leslie Espinosa, not a generally available hosted service. Use requires the account owner’s authorization and must be limited to data the owner is entitled to manage.

Account authorization does not constitute approval for every possible action. Destructive operations and changes to file sharing require the owner’s applicable instruction. Google services remain subject to Google’s terms and policies.

No subscription, uptime promise, or guarantee of successful backup or restoration is offered by this information page. Backup copies must be verified before local data is removed.
