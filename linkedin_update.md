## About

Most businesses didn't have an automation problem. They had an AI-cost problem they didn't see coming.

An autonomous AI agent can burn **5–30× the tokens of a single chatbot call** (Gartner) — every step it "thinks" through, you pay for. And today's API prices are still propped up below true compute cost by venture money; Sequoia famously called the gap the industry's **"$600B question."** The repricing has already started — GitHub priced some premium AI models at **3.6–6× the base rate**. When the subsidy fully unwinds, the bill doesn't land on the AI vendor. It lands on you.

I'm an **Automation Architect** who builds the antidote: **cost-resilient, deterministic automation infrastructure** that minimizes AI on purpose.

Here's the philosophy. Most operational work — validation, routing, syncing, reconciliation, notifications — is fully predictable. It doesn't need a large language model; it needs **deterministic logic** that's free to run, can't hallucinate, and never depends on someone else's uptime. So that's where the heavy lifting goes: into self-hosted orchestration I run on **your** infrastructure (n8n on Docker Compose behind Traefik, with Supabase, Postgres, and Qdrant). AI stays on a leash — used surgically, only where it genuinely earns its cost, and kept cheap with hybrid model routing and semantic caching.

What that buys you:
- **Predictable costs.** The deterministic core spends zero tokens. Your bill stops scaling with every transaction.
- **No third-party fragility.** Self-hosted means no API to rate-limit you, reprice you, or go down mid-operation.
- **No hallucinations where it matters.** A rule can't invent a number into an invoice or a client record. Business-critical paths stay deterministic.

The track record: **120+ operational processes automated**, **$800K+ in hard-dollar savings**, across intake, case and record management, billing, and client communication. Real systems running in production — most of them migrating a business off fragile, high-token AI wrappers and onto robust, self-hosted orchestration. Every build ships with validation, retries, fallback paths, and PII-masked audit logging from day one, plus docs so your team owns it.

Background: enterprise Microsoft Cloud and multi-tenant IT + marketing automation for **Le Cordon Bleu International** — so I'm as comfortable in a large multi-tenant environment as I am wiring up a lean ops stack. Certified: n8n Level 2, AWS Cloud Practitioner, Azure AZ-900, Make & Zapier, GitHub Foundations.
